## Running locally

1. Run `npm install` to install dependencies. Bootstrap is pinned to the [`v6-dev`](https://github.com/twbs/bootstrap/tree/v6-dev) branch via `github:twbs/bootstrap#v6-dev`. A local Bootstrap checkout is optional, not required.
2. Run `npm start` and open <http://localhost:4000>.
3. Run `npm test` to build the site and run all linters.
